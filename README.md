# Cyberfort AI Register for WordPress

A read-only WordPress presentation layer for the approved public data projection supplied by Cyberfort AI Register. The connector key is used only in server-side WordPress HTTP requests and is never sent to browser JavaScript.

## Development

Run `find . -name '*.php' -not -path './.git/*' -print0 | xargs -0 -n1 php -l` to check PHP syntax.
